# Australian Lottery History Dashboard

澳洲 Powerball 与 Oz Lotto 历史开奖和统计分析静态网站，支持中文和英文，可随时切换彩种。分析基于已收录结果，展示历史频率、遗漏和号码结构。

## 功能

- **统一范围**：最近 10、20、50、100、300 期、全部（`all`）或自定义日期（`custom`）；默认最近 100 期。日期区间包含起止日，预设期数不受保留的自定义日期影响。
- **历史与结构**：完整号码、区间着色、频率热力、连号、单期统计；Powerball 支持 PB 与主球重号；历史表按每页 50 期展示，可跳页。
- **号码分析**：主球与 PB／补充号分别查看频率、遗漏和近 10/20/50 期趋势；支持按频率、遗漏或号码排序。Oz Lotto 每期显示 7 个主号和 3 个补充号。
- **共现与图表**：Powerball 主球全部 595 对、Oz Lotto 全部 1,081 对的共现次数及理论期望，默认展示前 30 对，可展开全部；图表包含比例、区间与和值变化，并提供对应彩种的基线说明。
- **可点击详情**：单期号码和结构指标；号码的范围频率、截止期遗漏、滚动 10 期曲线、最近 50 期命中轨迹、全部出现日期。日期和号码可以互相跳转查看。
- **关注与复用**：各彩种独立保存主球和 PB／补充号关注列表、最多 10 个命名分析方案及浏览条件；链接的 `#` 部分保留彩种、视图、范围、球池、排序、页码和语言。关注号码不会筛掉统计样本。旧链接继续打开 Powerball，首次访问默认 Powerball，之后记住最后使用的彩种，分享链接优先。
- **CSV 导出**：导出当前分析范围的完整记录或对应统计，不受当前页或共现“前 30 对”展示限制；带实际样本数、范围和截止期等元数据。

关注列表、分析方案及最近使用状态保存在当前浏览器的 `localStorage`，没有账户或跨设备同步。清除网站数据、更换浏览器、切换站点域名/端口会影响可用的本地记录；浏览器禁止存储时，当前会话仍可使用，但保存可能失败。分享链接不包含关注列表或已保存方案。

## 统计口径

**频率**为号码出现次数除以实际开奖期数。Powerball 主球每期的理论出现率为 `7/35 = 20%`，PB 为 `1/20 = 5%`；Oz Lotto 主号为 `7/47`，补充号为 `3/47`。近 10/20/50 期列均在所选范围内取样；不足相应期数时显示实际样本。趋势差值比较最近 10 期与再之前 10 期，使用百分点；没有前窗口样本时不显示差值。号码详情的滚动曲线只使用该期和之前最多 9 期，开头按实际样本数计算。

**遗漏**以所选截止期为准，向前检查全部可用历史，不被起始日期或最近 N 期窗口截断，也不使用截止期之后的开奖。截止期出现的号码遗漏为 0；历史中从未观察到的号码显示 `≥N`。最长完整遗漏只计算两次已知出现之间的间隔，不包含历史首尾未完成的间隔；没有完整间隔时显示 `—`。

**理论基线**考虑不同号码集合的大小：Powerball 四个区间分别包含 10、10、10、5 个号码；主球奇偶为 18/17 个，小号/大号为 17/18 个。某一主球号码对在 N 期的期望共现次数为 `N × 7/35 × 6/34`。单期结构只统计 7 个主球，标准差采用总体标准差。

Oz Lotto 五个十位区间分别包含 10、10、10、10、7 个号码；主号奇偶为 24/23 个，小号/大号为 23/24 个。主号号码对的期望共现次数为 `N × 7/47 × 6/46`，单期理论和值为 168。区间着色为 1–16／17–32／33–47；补充号的奇偶比例按每期三个号码计算。结构与共现仍只使用主号。

历史频率、冷热、遗漏和共现都描述已有样本，不改变公平独立开奖中下一期的理论概率。

## 数据来源与自动更新

数据来自 [Lotterywest 官方频率统计页面](https://www.lotterywest.wa.gov.au/results/frequency-charts)提供的 Powerball 与 Oz Lotto CSV 下载。`db.js` 格式为 `["DD/MM/YYYY", 主球1, …, 主球7, PB]`；`db-ozlotto.js` 格式为 `["DD/MM/YYYY", 主号1, …, 主号7, 补充号1, 补充号2, 补充号3]`。号码为整数，主号和补充号各自升序，期数按日期降序。`data-status.json` 和 `data-status-ozlotto.json` 分别保存来源、最近尝试和最近成功同步状态。

Powerball 收录 **2018-04-19（第 1144 期）起**的现行规则：7 个 1–35 的主球及 1 个 1–20 的 PB。Oz Lotto 固定从 **2025-01-01** 起收录，首期为 **2025-01-07（第 1612 期）**；每期 7 个主号和 3 个补充号均在 1–47，十个号码互不重复，历史持续追加。官方 CSV 中更早的结果不会混入分析。历史首端是规则或数据覆盖边界，不能据此推断此前的遗漏。此数据源提供开奖日期、期号和号码；本网站没有据此提供奖金、购买记录或个人投注收益。CSV 是官方网页的下载功能，没有承诺稳定的版本化开发接口。

更新时检查日期、期号、球号范围、重复号码/日期、缺期、未来日期和与已保存结果的冲突。每个彩种独立更新；一个失败仍会尝试另一个。异常彩种保留原有效开奖数据和上次成功时间，并记录更新失败；不能把下载失败或过期结果当作新开奖。

GitHub Actions 工作流每天 **14:15 UTC** 尝试更新，也支持手动运行。公布缓冲使用 **Australia/Sydney** 本地时间，自动适配夏令时：Powerball 在**周五 12:00** 起要求最近周四结果，Oz Lotto 在**周三 12:00** 起要求最近周二结果；截止前允许再前一周的结果。定时任务的实际启动时间由 GitHub Actions 调度。

校验与测试通过后，工作流提交数据状态并构建、发布静态站点。更新失败时可发布保留的有效历史与失败状态，同时将报告任务标为失败；其他校验失败会阻止发布。来源限制、冲突处理和部署配置详见 [scripts/README.md](scripts/README.md)。

## 本地运行与验证

### Oz Lotto 手动预测页

独立地址为 `oz-lab-7f3c.html`，现有分析页面不提供入口。页面设置 `noindex, nofollow, noarchive`；静态 GitHub Pages 的隐藏地址不提供身份认证。

打开页面不会生成预测。点击“开始预测”后，四种可重放的选号规则分别生成一组 7 个主号，并保存当时的统计依据、历史截止期、目标期号、生成时间及规则版本。再次生成会新增版本，保留原记录。数据过期、不连续、少于 30 期或目标开奖日悉尼时间 19:00 后仍无新结果时暂停生成；这个时间是本页保守的事前预测截止线，不是官方销售截止时间。更新后的开奖记录用于核对已保存预测的主号、补充号命中及奖级，不会改写原预测。

记录使用独立的浏览器 `localStorage` 键 `oz-lotto-predictions:v1`，不上传服务器，不跨设备同步。请使用“导出备份”保存 JSON；“导入备份”校验后合并，不覆盖已有版本。存储失败会明确显示“未保存”，仍可导出当前会话的记录。备份文件可编辑，本地时间也可更改，记录不能作为独立可信的事前预测证明。各组解释描述历史样本及分散选择的规则，不代表中奖概率提高。

需要 **Node.js 22+**；以下预览命令还需要 **Python 3**。项目没有第三方运行依赖。

```sh
npm run serve
```

打开 `http://localhost:8765/`。页面使用 ES modules 并读取状态 JSON，需要通过 HTTP 服务访问；直接双击 `index.html` 的 `file://` 方式不能可靠加载这些资源。

```sh
npm test             # 运行离线自动测试
npm run validate     # 校验保存的开奖数据和状态一致性
npm run update-data  # 联网获取并校验官方结果，更新本地数据/状态
npm run update-data -- --game=ozlotto # 仅更新 Oz Lotto；也可指定 powerball
npm run build        # 将静态站点整理到 _site/，不上传或部署
```

`npm run build` 会重新生成 `_site/`，包含两套数据和同步状态。数据更新命令默认更新两个彩种，分别写入对应的数据库和状态文件；测试使用本地样本，不调用官方服务。

## 发布

添加工作流文件或运行本地构建不会自动启用线上更新；需要推送变更并启用下述发布配置。

准备发布时，将仓库 **Settings → Pages → Source** 设置为 **GitHub Actions**，允许工作流写入仓库内容，再将变更推送到当前工作流配置的 `master` 分支。完整步骤和工作流行为见 [更新与发布说明](scripts/README.md)。
